# Grandad's Detours

Escape room for SOUL English, Class 7, Module 2, Station 12 (ESZ Bad Düben).

The whole escape room is one file: `index.html`. All pictures and the Caveat font are inside it. With GitHub Pages switched on, the page runs at the address of the repository.

- Teacher view with all solutions: add `#lehrer` to the address.
- Progress is saved only in the browser of the device (localStorage). Nothing is sent anywhere.
